Not an ephemeral sandbox. A real computer that stays.

Unlike ephemeral sandboxes that start fresh every time, Mola gives your agent a persistent computer. Files, installed apps, browser sessions, and saved logins survive restarts. Stop to release compute, then wake it up right where you left off.

Credential vault for saved logins.

Your agent fills in passwords without seeing them. Logins stay saved across sessions. No need to reconfigure credentials every time your agent starts.

Live view of the desktop.

Watch what your agent is doing in real-time. Open the desktop to take over, debug, or hand it back to the agent. Embed views for monitoring agent fleets.

Create a Cloud computer

curl https://cloud.mola.sh/api/v1/computers \
  -H "Authorization: Bearer $MOLA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"research","image":"ubuntu"}'

Create an API token in your Cloud account to get started.

Open-source core. Self-host on your hardware.
