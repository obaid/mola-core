Create a Cloud computer

curl https://cloud.mola.sh/api/v1/computers \
  -H "Authorization: Bearer $MOLA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"research","image":"ubuntu"}'

Create an API token in your Cloud account to get started.
